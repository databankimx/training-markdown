# Exercise: Write a Setup Page

Write the Markdown for a short setup page. When you're done, its rendered output must match the description below.

## The description

The rendered page has these parts, in this order:

1. A top-level heading with the words Setup.
2. A paragraph that says: Install the tools in this order.
3. A bulleted list with three items: Git, Node.js 24, and The lesson runner.
4. A paragraph that says: To open the runner, run `npm start`. The text `npm start` is shown as code.
5. A table with two columns, headed Tool and Version, and two rows: Git with Any recent version, and Node.js with 24 or later.

## How to work

The starter contains the first line, so start from there. Type the rest of the Markdown in the Source pane.

- The Rendered pane updates as you type, so you can see the result as you go.
- The check compares your rendered output with the sample. It reports whether they match, and shows the hint if they don't.
- Press **Show solution (spoiler)** only after you've tried. It shows one correct answer.

Compare the rendered page with the description, part by part, as you go. A match is a match on what the page shows, so the spacing and the way you write each mark don't matter. The words, the emphasis, and the structure do.

> **A note on the check.** Check compares the rendered page, not your source. A list written with an asterisk and one written with a hyphen look the same on the page, so both pass. Italics and bold do not look the same, so a wrong one fails.
