# Markdown Basics

Markdown is plain text with a few marks that tell a viewer how to display it. You write headings with `#`, lists with `-`, and code in backticks, and the viewer turns those marks into headings, lists, and code blocks.

It's the format of the documents you'll read and write at work: READMEs, specifications, context documents, and notes. This short tutorial teaches the parts you'll use every day, and how to check a file before you share it.

Each lesson has a practice task. Save your practice files in a folder of your own.
